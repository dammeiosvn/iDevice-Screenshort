[**iScreenshort**](https://dammeiosvn.github.io/iDevice-Screenshort/iScreenshort+.mobileconfig)

Webclip iOS ghép ảnh chụp màn hình vào khung thiết bị.

Khung nằm trong `idevice/`. Màn hình khớp lỗ trong suốt của khung, bo góc bằng `*_mask.png`.

Sáng/tối theo `prefers-color-scheme`.

Bật GitHub Pages: Settings → Pages → branch `main` / root.

Thêm vào Màn hình chính từ Safari.
